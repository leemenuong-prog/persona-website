# 图版规范（凝练版）· Meco Plates v2

适用于作品详情页插图与封面。整个文件夹是草稿区（git 未跟踪），风格定稿后再谈接线。
重新生成：`python3 _gen.py`（输出到本目录，改一个数重跑即得）。

## 一、构图语言（按已验证的效果排序）

1. **玻璃容器 + 内部器官**（01，最佳）：线框壳体透视内部，白实体机器各司其职，盖板爆炸悬浮。
2. **阶梯面板**（02）：同一台座上一列白板叠瓦升阶，面上蚀刻微图表，形态差异即语义差异。
3. **核体 + 围栏**（03）：中央白实体，卫星体块分实/虚两族，点划围栏圈出禁区，引线线型即权限。
4. 封面：网壳穹顶 + 白柱 + 字标（品牌场景专用）。

**数量上限**：示意图版**每个项目页最多三张**，宁缺毋滥；多出的概念合并或舍弃。

**具象克制**：拟态形象（蘑菇、信号桅这类"像什么"的造型）难控制，尽量少做——
封面字标场景可用，正文图版一律用抽象体块（盒、板、柱、鼓）表意。

## 一之二、整体流程横图（模板 · 每个项目页必备）

技术栈正下方（`contentImages[0]` 槽位）固定放一张**讲清整个 App 的流程横图**，配文字球图注。

- 画幅 `1200×520` 横幅；2D，不用轴测。
- **三段式**：左列入口节点 → 中央主体大框 → 右列去处节点；连线带小箭头。
- 节点 = 白底直角方块 + 顶部小图形 + **small-caps 衬线节点名**（letter-spacing 3，#6F6F6F）；
  只允许产品/端点名（Feishu、Obsidian…），不写系统黑话。
- 中央主体框是全图唯一 L0，内部放 2–3 个小图形交代主要构件（数量可数即语义，如 8 格 = 8 工具）。
- 线上注释用斜体衬线小字（#999999），只写人话动词短语（"read-only." / "on time."）。
- 只读/单向关系：L3 虚线 + 指向箭头。
- 底部一行斜体收束句（同图版文字规则）。

## 二、形态词汇表（形 → 义，跨图版保持一致）

| 形 | 义 |
|---|---|
| 玻璃线框体 | 只可看、不可写 |
| 白填充实体 | 可动手、真实存在 |
| 虚线 | 被遮挡 / 穿入内部 / 只读方向 |
| 点划围栏（地界线式） | 权限边界 |
| 爆炸悬浮 + 点线轨迹 | 打开给你看 |
| 顶面刻齿环（60 齿 / 每 15 一长齿） | 时间、节拍 |
| 45° 剖面排线 | 切开的实体（制图惯例） |
| 实心墨方（8–13px） | 句点 / 一次抵达。**全套至多两处** |

## 三、投影与线级（生成脚本唯一权威）

等轴测 30°：`sx = OX + (x−y)·0.8660254`，`sy = OY + (x+y)·0.5 − z`（1 世界单位 = 1px）。
水平圆 → 椭圆：`rx = 1.2247·R`，`ry = 0.7071·R`。可见面恒为 顶 / x+ / y+；
汇于远底角 `(x₀,y₀,z₀)` 的 3 棱是隐藏边。面上微图表用 `<g transform="matrix(…)">` 贴 uv 平面绘制。

| 级 | 用途 | 描边 |
|---|---|---|
| L0 | 每版唯一主角的轮廓 / 剖切线 / 主角线 | #181818 · 1.5 · 实 |
| L1 | 可见棱线、主连线 | #6F6F6F · 1 · 实 |
| L2 | 蚀刻（微图表、格栅、刻齿、排线） | #BEBEBE · 1 · 实 |
| L3 | 隐藏边 / 玻璃透视边 | #BEBEBE · 1 · dash 7 5 |
| L4 | 围栏 | #6F6F6F · 1 · dash 14 5 2 5 |
| L5 | 构造线（轨迹 2 6 / 中心轴 16 5 2 5） | #E0E0E0 · 0.75 |

## 四、铁律

1. 第一元素必须是满幅白底 `<rect fill="#FFFFFF">`（站内 lightbox 是透明壳叠黑遮罩，透明底会不可读）。
2. 不画外框（页面 figure 自带 1px 边框）；几何收进四边 ≥90px 留白。
3. 全体图元 `vector-effect: non-scaling-stroke`；根元素带 width/height；虚线 dash ≥6。
4. 只用灰阶四色 + 白；面填充只有 `#FFFFFF`（遮挡）或 `none`（玻璃），零灰面，零彩色。
5. 图版内不出现编号、标签、任何解释性文字——除下述「一行英文」和封面字标。

## 五、文字（英文 only，克制）

**组件标注**：允许给图版加少量英文组件名（斜体小字 19px、#999999、可配 L5 发丝引线），
只命名部件、不写句子（"the bot." / "calendar." / "read-only."）；用人话词，不用系统黑话。

**防遮挡（硬规则）**：标注文字不允许被任何线穿过——位置优先落空白区；所有图内文字一律带白色光环
`paint-order="stroke" stroke="#FFFFFF" stroke-width="7-8" stroke-linejoin="round"`（制图挖空惯例），
引线先画、文字后画，保证文字永远压在最上层。
页面层 figcaption **不再使用**——图版自带说明，projects.json 的 figure 只留 src。
中文直译的比喻词（"器官""五域"这类）不进任何面向读者的中文文案。

### 收束句（每版至多一行）

- **式样**：小写斜体衬线，`Garamond → EB Garamond → Georgia` 栈；1200 宽画幅下
  font-size 26、letter-spacing 1.5、`#999999`；底部居中，`y = 画幅高 − 44`。
- **口吻**：说人话的极简短句，点到含义即止；**禁系统性词汇**
  （process / API / system / data / whitelist / schedule / sync…）。
- 现行六句：
  - 01 `one body, four organs.`
  - 02 `five views of one life.`
  - 03 `look, don't touch.`
  - 04 `never out of touch.`
  - 05 `in, through, out.`
  - 封面副题 `a homegrown butler.`（字标 MECO + 墨方句点之下，21px）

## 六、画幅

正文图版 `1200×750`（横长构图可 `1200×640`）；封面 `720×720`（需在 360px 卡片尺度自检）。
验收三档：760 栏宽 / 340 移动 / lightbox 放大（本目录 index.html 自带三档预览）。
